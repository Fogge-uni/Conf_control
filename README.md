# Вариант 5

## Этап 1
## Общее описание
На первом этапе был разработан минимальный прототип, в котором выполняются следующие функции:
- Приглашение к вводу, начинающееся с имени VFS.
- Отработка аргументов в кавычках
- Отработка ошибок (неизвестная кманда, неверные аргументы)
- Команды "ls" и "cd", выводящие свое имя и введеные аргументы
- Команда exit, завершающая работу программы
## Описание классов и методов
Для выполнения этапа 1 были разработаны 3 класса:
- Класс Main, запускающий программу и создающий объект оболочки с данным именем VFS при помощи метода main
- Класс Shell, сохраняющий имя VFS и запускающий интерактивый режим работы, выполняя полученные команды, при помощи
  метода run. Отработка ошибок совершается при помощи try catch.
- Класс Parser, разбирающий введенную строку на команды и аргументы и отрабатывающий кавычки при помощи метода parse.
  Отработка ошибок совершается при помощи try catch.
## Описание настроек
Первый этап не требовал использование параметров командрой строки, а имя VFS задается в программе при создании
объекта Shell и имеет значение default.

## Этап 3
## Общее описание
На третьем этапе была подключена виртуальная файловая система:
- Все операции производятся в памяти, все модификации производятся исключительно
при помощи возможных служебных команд
- Реализована загрузка VFS из JSON-файла.
- Производится отработка ошибок (файл не найден, неверный формат)
- поддерживается вывод сообщения из файла motd при запуске программы. 
- Созданы несколько скриптов реальной OC, в которой выполняется эмулятор
- Создан стартовый скрипт для тестирования всех реализованных команд
## Описание классов и методов
Для выполнения этапа 3 были добавлены и изменены следующие классы:
- Класс VirtualFileSystem отвечает за загрузку виртуальной файловой системы из
JSON, создание VFS по умолчанию и получение содержимого файла motd.
- Класс VfsNode описывает отдельный элемент виртуальной файловой системы, храня имя файла, его содержимое
и дочерние элементы
- Класс JsonParser разбирает JSON-файл и проверяет его формат.
- Класс Main теперь загружает VFS при запуске программы, проверяет ошибки
загрузки и выводит содержимое motd.
- Класс Shell был связан с VFS
## Описание настроек
Была добавлена отработка ошибок при отсутсвии или неверном формате файла при 
использовании параметра --vfs
## Описание команд для сборки и запуска тестов
Для сборки и запуска проекта, выполняется ./run.bat c вручную введенными параметрами

Для запуска с заданной VFS:
.\run.bat --vfs vfs\minimal.json

Для запуска стартового скрипта:
.\run.bat --script tests\start.txt

Для запуска с заданной VFS и стартовым скриптом:
.\run.bat --vfs vfs\minimal.json --script tests\start.txt

Были созданы отдельные скрипты для проверки работы VFS
