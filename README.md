# Вариант 5

Эмулятор исходной оболочки операционной системы в виде консольного приложения (CLI)
## Этап 1
## Общее описание
На первом этапе был разработан минимальный прототип, в котором выполняются следующие функции:
 - Приглашение к вводу, начинающееся с имени VFS.
 - Отработка аргументов в кавычках
 - Отработка ошибок (неизвестная кманда, неверные аргументы)
 - Команды "ls" и "cd", выводящие свое имя и введеные аргументы
 - Команда exit, завершающая работу программы
## Описание классов и методов
Для выполнения этапа 1 были разработаны 3 класса:
 - Класс Main, запускающий программу и создающий объект оболочки с данным именем VFS при помощи метода main
 - Класс Shell, сохраняющий имя VFS и запускающий интерактивый режим работы, выполняя полученные команды, при помощи 
метода run. Отработка ошибок совершается при помощи try catch.
 - Класс Parser, разбирающий введенную строку на команды и аргументы и отрабатывающий кавычки при помощи метода parse.
Отработка ошибок совершается при помощи try catch.
## Описание настроек
Первый этап не требовал использование параметров командрой строки, а имя VFS задается в программе при создании 
объекта Shell и имеет значение default.
## Описание команд для сборки и запуска тестов
Для сборки и запуска проекта выполняется ./run.sh

Для проведения тестов необходимо вручную ввести необходимые команды после запуска
программы
## Примеры использования

### Запуск программы
default>
### Пример выполнения команды ls
default> ls aaa <br>ls [aaa]

default> ls a a a<br>
ls [a, a, a]
### Пример аргумента в кавычках
default> ls "hello world" <br>
ls [hello world]
### Пример выполнения команды cd
default> cd hi <br>
cd [hi]
### Пример обработки ошибок
default> ls "hola <br>
Ошибка: кавычки не закрыты

default> abcd <br>
Ошибка: неизвестная команда

default> exit ehehe <br>
Ошибка: exit не принимает аргументы
### Завершение работы программы
default> exit <br>
Process finished with exit code 0
